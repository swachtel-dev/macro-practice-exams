# ECONM-I Practice Exams

Static interactive HTML pages for the ECONM-I (Principles of Macroeconomics) practice midterm and final.

Source lives in the coursedev repo at `/Users/samuel/Desktop/Mucking/projects/coursedev/ECONM-I/`. Regenerate with:
```bash
python3 bank-scripts/render_practice_exam_html.py both
```
Then copy the two HTML outputs into `midterm/index.html` and `final/index.html` and push.
